1. 로또 자동 구매
   
#기능 목록
[O] 로또 구입 금액 입력
[O] 구입 금액 기준 로또 구매 수령 계산
[O] 로또 한 장에 중복되지 않는 숫자 6개 뽑음
[O] 로또 번호를 오름차순으로 정렬
[O] 구입한 로또 수량을 출력
[O] 생성된 모든 로또 번호 출력

#구현 조건
- 로또 한 장 가격: 1000원
- 배열X 컬렉션O
- Collections.shuffle()사용해 번호 섞음/ .sort()사용해 번호 정렬
- 삼항 연산자X
- else사용X
- 메서드 한 가지 일만 담당
- 들여쓰기 깊이 1까지

2. 로또 당첨

#기능 목록
[] 구입 금액 입력
[] 구입 금액이 숫자인지 확인
[] 구입 금액이 1000원 단위인지 확인
[] 구입 금액에 따라 로또 구매 개수 계산
[] 로또 1장마다 1부터 45사이의 숫자 6개 생성
[] 한 장의 로또에 중복된 번호가 들어가지 않도록함
[] 셍성된 로또 번호를 오름차순 정렬
[] 구매한 로또 개수와 번호 출력

#당첨 번호 입력
[ ] 지난주 당첨 번호 6개를 입력받음
[ ] 당첨 번호를 쉼표 기준으로 구분
[ ] 당첨 번호가 숫자인지 확인
[ ] 당첨 번호가 1부터 45 사이인지 확인
[ ] 당첨 번호가 정확히 6개인지 확인
[ ] 당첨 번호에 중복된 숫자가 없는지 확인

#당첨 결과 계산
[ ] 구매한 로또와 당첨 번호 비교
[ ] 일치하는 번호의 개수를 계산
[ ] 3/4/5/6개 일치 로또의 개수를 계산

#당첨 통계 출력
[] 각 등수의 당첨 횟수 출력
[] 전체 당첨 금액 계산
[] 구입 금액을 기준으로 총수익률 계산
[] 총수익률을 소수점 둘째 자리까지 출력

#당첨 기준
- 3개> 5000원
- 4개> 50000
- 5개> 1500000
- 6개> 2000000000

#예외 처리
- 구입 금액이 숫자가 아닐 시
- 구입 금액이 1000원 미만/ 단위가 아닐 시
- 로또 번호가 1부터 45 사이가 아닐 시
- 로또 번호가 6개가 아닐 시
- 로또 번호가 중복될 시
