1. 로또 자동 구매
   
#기능 목록
[O] 로또 구입 금액 입력
[O] 구입 금액 기준 로또 구매 수령 계산
[O] 로또 한 장에 중복되지 않는 숫자 6개 뽑음
[O] 로또 번호를 오름차순으로 정렬
[O] 구입한 로또 수량을 출력
[O] 생성된 모든 로또 번호 출력

#구현 조건
- 로또 한 장 가격: 1000원
- 배열X 컬렉션O
- Collections.shuffle()사용해 번호 섞음/ .sort()사용해 번호 정렬
- 삼항 연산자X
- else사용X
- 메서드 한 가지 일만 담당
- 들여쓰기 깊이 1까지

2. 로또 당첨

#기능 목록
[o] 구입 금액 입력
[o] 구입 금액이 숫자인지 확인
[o] 구입 금액이 1000원 단위인지 확인
[o] 구입 금액에 따라 로또 구매 개수 계산
[o] 로또 1장마다 1부터 45사이의 숫자 6개 생성
[o] 한 장의 로또에 중복된 번호가 들어가지 않도록함
[o] 셍성된 로또 번호를 오름차순 정렬
[o] 구매한 로또 개수와 번호 출력

#당첨 번호 입력
[o] 지난주 당첨 번호 6개를 입력받음
[o] 당첨 번호를 쉼표 기준으로 구분
[o] 당첨 번호가 숫자인지 확인
[o] 당첨 번호가 1부터 45 사이인지 확인
[o] 당첨 번호가 정확히 6개인지 확인
[o] 당첨 번호에 중복된 숫자가 없는지 확인

#당첨 결과 계산
[o] 구매한 로또와 당첨 번호 비교
[o] 일치하는 번호의 개수를 계산
[o] 3/4/5/6개 일치 로또의 개수를 계산

#당첨 통계 출력
[o] 각 등수의 당첨 횟수 출력
[o] 전체 당첨 금액 계산
[o] 구입 금액을 기준으로 총수익률 계산
[o] 총수익률을 소수점 둘째 자리까지 출력

#당첨 기준
- 3개> 5000원
- 4개> 50000
- 5개> 1500000
- 6개> 2000000000

#예외 처리
- 구입 금액이 숫자가 아닐 시
- 구입 금액이 1000원 미만/ 단위가 아닐 시
- 로또 번호가 1부터 45 사이가 아닐 시
- 로또 번호가 6개가 아닐 시
- 로또 번호가 중복될 시

3. 로또 2등 당첨

# 로또 구입 금액 입력
- 사용자에게 로또 구입 금액을 입력받음
- 구입 금액은 1,000원 단위
- 구입 금액을 이용해 구매할 로또 개수 계산

# 로또 자동 생성
- 로또 한 장은 1부터 45까지의 숫자 중 서로 다른 6개의 숫자로 구성
- 로또 번호는 오름차순으로 정렬
- 구입 금액에 해당하는 개수만큼 로또 생성

# 구입한 로또 출력
- 구매한 로또 개수를 출력
- 생성한 로또 번호를 한 줄에 하나씩 출력

# 지난주 당첨 번호 입력
- 지난주 당첨 번호 6개를 쉼표로 구분하여 입력받음
- 당첨 번호는 1부터 45 사이의 숫자
- - 당첨 번호에는 중복된 숫자가 없어야함

# 보너스 번호 입력
- 2등 판정을 위한 보너스 번호를 입력받음
- 보너스 번호는 1부터 45 사이의 숫자
- 보너스 번호는 기존 당첨 번호 6개와 중복될 수 없음

# 당첨 등수 계산
- 로또 번호와 당첨 번호가 몇 개 일치하는지 계산
- 3개가 일치> 5등
- 4개가 일치> 4등
- 5개가 일치, 보너스 번호가 일치X 3등
- 5개가 일치, 보너스 번호가 일치O> 2등
- 6개가 일치> 1등
- 2개 이하가 일치하면 당첨되지 않은 것으로 처리

# 당첨 통계 출력
[o] 각 등수별 당첨 개수 출력
[o] 3개 일치부터 6개 일치까지의 결과 출력
[o] 2등은 `5개 일치, 보너스 볼 일치`로 출력

# 수익률 계산
- 모든 당첨금의 합계 계산
- 총 당첨금을 구입 금액으로 나누어 수익률 계산
- 계산한 수익률을 출력

# 프로그래밍 요구사항
[o] Java Enum을 사용하여 당첨 등수를 관리
[o] 자바 코드 컨벤션을 지킴
[o] 들여쓰기 깊이는 1까지만 허용
[o] 삼항 연산자 사용X
[o]`else` 예약어 사용X
[o] `switch/case` 사용X
[o] 배열 대신 컬렉션을 사용
[o] 축약어를 사용X
[o] 하나의 메서드는 한 가지 역할만 수행하도록 작성
[o] 메서드의 길이가 10라인을 넘지 않도록 작성
[o] 원시 값과 문자열을 객체로 포장
[o] 로또 목록을 일급 컬렉션으로 관리

4. 로또 수동 구매

# 구입 금액 입력
- 로또 구입 금액을 입력받음
- 구입 금액이 숫자인지 확인
- 구입 금액이 1,000원 이상인지 확인
- 구입 금액이 1,000원 단위인지 확인
- 구입 금액을 이용해 전체 로또 구매 개수를 계산

# 수동 구매 개수 입력
[ ] 수동으로 구매할 로또 개수를 입력받음
[ ] 수동 구매 개수가 숫자인지 확인
[ ] 수동 구매 개수가 0 이상인지 확인
[ ] 수동 구매 개수가 전체 구매 개수를 넘지 않는지 확인
[ ] 전체 구매 개수에서 수동 구매 개수를 빼 자동 구매 개수를 계산

# 수동 로또 번호 입력
[ ] 수동 구매 개수만큼 로또 번호를 입력받음
[ ] 쉼표를 기준으로 번호를 구분
[ ] 로또 번호가 숫자인지 확인
[ ] 로또 번호가 1부터 45 사이인지 확인
[ ] 로또 번호가 6개인지 확인
[ ] 로또 번호에 중복이 없는지 확인
[ ] 입력된 로또 번호를 오름차순으로 정렬

# 자동 로또 생성
[ ] 자동 구매 개수만큼 로또를 생성
[ ] 1부터 45 사이의 숫자 중 6개를 생성
[ ] 생성된 번호에 중복이 없도록 함
[ ] 생성된 번호를 오름차순으로 정렬

# 구매 결과 출력
[ ] 수동 구매 개수와 자동 구매 개수 출력
[ ] 수동 로또를 먼저 출력
[ ] 자동 로또를 수동 로또 다음에 출력

# 당첨 번호 입력
- 지난주 당첨 번호 6개를 입력받음
- 당첨 번호가 1부터 45 사이인지 확인
- 당첨 번호가 6개인지 확인
- 당첨 번호에 중복이 없는지 확인

# 보너스 번호 입력
- 보너스 번호를 입력받음
- 보너스 번호가 숫자인지 확인
- 보너스 번호가 1부터 45 사이인지 확인
- 보너스 번호가 당첨 번호와 중복되지 않는지 확인

# 당첨 결과 계산
- 구매한 로또와 당첨 번호 비교
- 일치하는 번호 개수 계산
- 보너스 번호 일치 여부를 확인
- 당첨 등수 계산

# 당첨 통계 출력
[ ] 3/ 4/ 5개 일치 결과 출력
[ ] 5개 일치 및 보너스 번호 일치 결과 출력
[ ] 6개 일치 결과 출력
[ ] 총 수익률 출력

# 예외 처리
[ ] 잘못된 값을 입력하면 `IllegalArgumentException`발생
[ ] 예외 메시지를 출력한 후 해당 입력을 다시 받음
[ ] 모든 예외 메시지는 `[ERROR]`로 시작
